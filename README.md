## About me

I enjoy taking technically ambitious ideas all the way from research and system design to tested, usable products. My work spans full-stack web platforms, AI-powered applications, data-intensive services, interactive 3D visualization, and developer tooling.

- **Full-stack engineering:** responsive interfaces, APIs, authentication, payments, real-time features, data modeling, and production deployment
- **AI engineering:** LLM applications, RAG, embeddings, vector search, multi-agent workflows, computer vision, and model interpretability
- **Data science:** data processing, predictive modeling, uncertainty analysis, experimentation, and interactive visualization
- **Engineering quality:** typed systems, automated tests, CI pipelines, containers, observability, and reproducible workflows

## Selected work

| Project | What it demonstrates | Core stack |
|---|---|---|
| [**Deepwalker**](https://github.com/MarinJursic/Deepwalker) | High-precision knowledge extraction with LLMs, vector-density analysis, HNSW indexing, and engineering-grade rulebook generation | Python · RAG · Embeddings · Ollama · Vector search |
| [**Cortex**](https://github.com/MarinJursic/Cortex) | Multimodal text, audio, and video analysis visualized as predicted cortical activity on an interactive 3D brain | Next.js · TypeScript · FastAPI · Three.js · AI |
| [**Autonomous Motion Forecasting Lab**](https://github.com/MarinJursic/autonomous-motion-forecasting-lab) | Interactive trajectory and occupancy-flow forecasting with calibrated uncertainty and causal counterfactuals | Next.js · FastAPI · Three.js · Python |
| [**BranchTrace Circuit Explorer**](https://github.com/MarinJursic/branchtrace-circuit-explorer) | A mechanistic-interpretability workbench for tracing neural circuits and testing causal hypotheses | Next.js · FastAPI · Explainable AI · Testing |
| [**Dynamic Gaussian Scene Intelligence**](https://github.com/MarinJursic/dynamic-gaussian-scene-intelligence) | A local-first image/video-to-space workbench with semantic layers, navigable scenes, and PLY export | TypeScript · Python · Three.js · Computer vision |
| [**Global Wildfire Risk Globe**](https://github.com/MarinJursic/global-wildfire-risk-globe) | Geospatial ignition-risk and spread forecasting with uncertainty and exposure analysis on an interactive globe | Next.js · FastAPI · Three.js · Data visualization |
